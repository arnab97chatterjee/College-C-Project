# Employee Payroll Management System (C Language)

A console-based application built in C to streamline employee record management and automate salary calculations.

## 📌 Features
* **Add Employee:** Store employee details (ID, Name, Basic Salary, etc.).
* **Calculate Salary:** Automatically compute gross salary, deductions (tax, PF), and net salary.
* **Update Records:** Modify existing employee data.
* **View Payroll:** Display formatted payslips for all employees.
* **File Handling:** Save records permanently using `.txt` or binary files.

## 🛠️ Tech Stack
* **Language:** C
* **Tools:** VS Code, GCC Compiler
* **Concepts Used:** Structures, File I/O, Pointers, Functions (Iterative & Recursive), Loops.

## 📂 Folder Structure
* `Source Code/`: Contains the main `.c` files.
* `Documentation/`: Project report and logic flow.
* `Presentation/`: Project defense slides.
* `Testing/`: Test cases and edge case scenarios.

## 🚀 How to Run
1. Clone this repository.
2. Open terminal in the `Source Code` folder.
3. Compile: `gcc main.c -o payroll`
4. Run: `./payroll` (or `payroll.exe` on Windows)
